Add a book to the shelf

How this works right now: this site doesn't have a live server behind it yet, so this page can't save a book by itself. Fill in the form, click Generate entry, then copy the code it gives you and paste it into js/books-data.js (inside the square brackets, as a new item). Save the file and push it to GitHub — the new book will appear for everyone. See the note at the bottom of this page for how to make this fully automatic later. 

    
  


  

    Making this automatic later: right now every visitor sees the same
    books-data.js file that lives in your GitHub repo — there's no database, so this
    form can't write to it directly from the browser. When you're ready for a real "upload a book and
    it just appears" backend, the usual next step is a free hosted database like Supabase, or a small
    Node.js server on a host like Render — both can plug into this same frontend without a rebuild.
